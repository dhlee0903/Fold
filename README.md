# 폴드 종이접기 (Fold Origami)

갤럭시 Z 폴드처럼 **접히는 기기의 힌지 각도를 읽어서, 기기를 실제로 접으면 화면 속 종이가 같이 접히는** 안드로이드 앱입니다.

기기를 한 번 접었다 펴면 종이접기 한 단계가 진행됩니다. 접는 도중에는 힌지 각도가 그대로 종이의 접힘 각도로 이어져서, 손에 든 기기와 화면 속 종이가 같은 각도로 움직입니다.

```
힌지 센서(0~180°) ──▶ 접힘 진행률 t ──▶ 접기 상태 기계 ──▶ 종이 모델 ──▶ 화면
  TYPE_HINGE_ANGLE      t = (180-각도)/180    한 번 접었다 펴면    면/겹 계산      Compose Canvas
  WindowManager 접힘 상태                      한 단계 확정
```

## 어떻게 동작하나

| 단계 | 하는 일 |
| --- | --- |
| 힌지 읽기 | `Sensor.TYPE_HINGE_ANGLE`(안드로이드 11+)로 0~180°를 연속으로 받습니다. 센서가 없으면 Jetpack WindowManager의 `FoldingFeature` 상태(펼침/반접힘)로 대신합니다. |
| 진행률 변환 | 180°(완전히 펴짐)를 0, 0°(완전히 닫힘)를 1로 봅니다. |
| 단계 확정 | 진행률 **0.72**(약 50°)를 넘으면 현재 단계를 확정하고, 다시 **0.20**(약 145°) 아래로 펴야 다음 단계를 접을 수 있습니다. |
| 종이 접기 | 주름선을 기준으로 각 면을 잘라 반사시키고, 넘어간 겹은 순서를 뒤집어 위(골접기) 또는 아래(산접기)에 쌓습니다. |

> **왜 0°가 아니라 50°에서 확정하나요?**
> 폴드류 기기는 완전히 닫히기 전에 큰 화면이 꺼집니다. 화면이 살아 있는 동안 단계가 넘어가도록 확정 기준을 넉넉히 앞당겼습니다.

## 들어 있는 것

- **부채** — 1/4씩 번갈아 접어 주름을 만듭니다. 산접기와 골접기의 차이가 눈에 보입니다.
- **종이 모자** — 반 접고 양쪽 모서리를 모은 뒤, 아래 띠를 앞장/뒷장 따로 접어 올립니다.
- **종이비행기** — 반 접고 앞장·뒷장으로 코를 만든 다음 날개를 접습니다.
- **자유 접기** — 화면에서 **접을 점 → 도착할 점**으로 손가락을 끌면 두 점을 포개는 주름선(수직이등분선)이 생깁니다. 골접기/산접기, 전체 겹/앞장만을 고를 수 있습니다.

접히지 않는 기기에서는 화면 아래의 수동 조절기로 같은 동작을 확인할 수 있습니다.

## 프로젝트 구조

```
origami-core/     순수 코틀린 접기 엔진 (안드로이드 의존성 없음, 테스트 40개)
  Geometry.kt     벡터·주름선·반평면 자르기
  Paper.kt        면/겹 모델, 접기 적용, 중간 각도 자세 계산
  Models.kt       작품별 접기 설명서
  FreeFold.kt     "이 점을 저 점에 포개기" 한 단계 만들기
  FoldSession.kt  힌지 각도 → 단계 진행 상태 기계

app/              안드로이드 앱 (Jetpack Compose)
  fold/           힌지 각도 센서 + WindowManager 접힘 상태 수집
  ui/             화면, 종이 그리기 캔버스, 상태 보관(ViewModel)
```

접기 엔진을 안드로이드에서 떼어 놓았기 때문에, 기하 계산은 기기 없이 JVM 테스트로 검증합니다.

### 종이를 어떻게 표현하나

접힌 종이는 **면(facet)들의 목록**입니다. 각 면은 눌러서 평평하게 폈을 때의 다각형과, 몇 번째 겹인지, 앞면이 보이는지 뒷면이 보이는지를 들고 있습니다.

한 단계를 접으면
1. 주름선으로 각 면을 두 조각으로 자르고,
2. 움직이는 쪽을 주름선에 대해 반사시키고,
3. 넘어간 겹들의 순서를 뒤집어 남은 뭉치 위(또는 아래)에 얹습니다.

접는 도중(0~180°)에는 반사 대신 주름선을 축으로 회전시켜 정사영으로 그립니다. 각도가 180°가 되면 반사한 결과와 정확히 같아지므로, 애니메이션과 최종 결과가 어긋나지 않습니다.

"앞장만 접기"는 종이 전체가 아니라 **주름선 너머에 걸쳐 있는 면들** 중에서 겹을 셉니다. 종이접기 설명서의 "앞장만 접으세요"와 같은 뜻입니다.

## 빌드하기

```bash
# 접기 엔진 테스트 (안드로이드 SDK 없이 됩니다)
./gradlew :origami-core:test

# 앱 빌드 (ANDROID_HOME 또는 local.properties의 sdk.dir 필요)
./gradlew :app:assembleDebug
```

안드로이드 SDK를 찾지 못하면 `:app` 모듈은 자동으로 빠지고 접기 엔진만 빌드됩니다. SDK가 깔려 있어도 `-PincludeApp=false`를 주면 엔진만 검사합니다(CI가 이렇게 돕니다). 안드로이드 스튜디오로 열면 SDK 경로가 잡혀 있으므로 앱까지 그대로 빌드됩니다.

- `minSdk` 26 / `targetSdk` 35
- 힌지 각도 센서는 안드로이드 11(API 30)+에서만 동작하며, 없으면 접힘 상태나 수동 조절기로 대체됩니다.
- 폴더블은 접었다 펼 때 설정 변경이 잦으므로 액티비티가 다시 만들어지지 않게 `configChanges`를 지정하고, 진행 상황은 `ViewModel`에 둡니다.

## 앞으로

- 뒤집기(전체 뒤집기) 동작과 안쪽 접기·바깥 접기 같은 복합 주름 지원
- 학처럼 여러 겹을 한꺼번에 여는 단계가 있는 작품
- 완성한 작품을 이미지로 저장/공유
